EMM figure builder

Paste LaTeX tables of estimated marginal means (or add a jamovi PDF) to draw single or paneled figures.

How to use this tool

Quick start

  1. Paste LaTeX table code (or jamovi text) into the box and click Load tables, or add a file below it: .tex, .txt, or a jamovi PDF.
  2. Pick a table in Panel A, then choose what goes on the x-axis, what is colored, and what splits into sub-panels.
  3. Click Add panel to put more tables in one figure, and set Columns to arrange them in a grid.
  4. Style the figure, then export as SVG or PNG.

1. Load results

  • Needs estimated marginal means tables: a heading like “Estimated Marginal Means - A ✻ B”, then rows of factor levels with Mean, SE, (df), Lower and Upper.
  • LaTeX tables take their factor order and columns from the header row, so a missing df column is fine. Paste several tables at once.
  • Reading a PDF needs an internet connection. If it fails, paste the text instead.

2. Panel fields

  • Table: which set of means to plot.
  • Display: points and lines, lines with a shaded CI band, or bars.
  • X axis / Color by / Split into panels by: assign factors to roles. “Split” makes one sub-panel per level. With no split, any factor you haven’t assigned is held at its first level and named in the panel heading, so you always start with one panel.
  • X axis title, Y axis title: custom text. Blank uses the factor name (x) or the Y label in Style (y).
  • X tick labels: new names for the x levels, comma-separated, in the order shown.
  • Legend title, Legend labels: rename the legend and its entries (labels in legend order).
  • Panel titles: headings for split panels, in order. Use | between titles that contain commas.
  • Colors: names or hex codes in legend order. Blank slots keep the palette color.
  • Line styles: solid, dashed, dotted, dashdot or longdash, in legend order. Lines and bands only.
  • Type [blank] in any title or label field to hide it. For lists, [blank] alone hides all, or use it as one entry to hide just that one.

3. Style (applies to the whole figure)

  • Font, size, palette: text and default group colors (colorblind-safe, muted or grayscale).
  • Error bars: 95% CI or ± SE. It sets the bars, error bars and ribbon bands.
  • Line width, point size: line and marker thickness.
  • Line shape: sharp joins the means with straight segments. Smoothed draws a curve through the same means (and through the upper and lower CI bounds for ribbons). It is for appearance only and adds no information.
  • Columns: panels per row. Plot width/height: size of each plot area in pixels.
  • Y min / Y max: blank means automatic (bars always include 0). Y label: default y-axis title for all panels.
  • Shared y-axis: same scale across panels so they compare directly. Gridlines, Legends, Panel letters: toggles. Panel labels: your own letters in order, e.g. B, C. A single letter such as B continues as B, C, D. [blank] hides them.
  • Legend position and layout: outside (right, below, above) or inside a corner or edge, vertical or horizontal. X label rotation: angle for long tick labels.

4. Export

  • SVG is editable in Illustrator or Inkscape. PNG is saved at 3× size.
  • Save settings stores your styles and panels. After loading the same tables again, Load settings rebuilds the figure.

Good to know

  • The x-axis treats levels as evenly spaced categories.
  • Values are only as precise as the source table, and LaTeX tables are often rounded.
  • This tool plots estimated means and intervals only. It does not run statistics or draw significance brackets.
  • For a 3-way interaction, put one factor on the x-axis, one in Color by, and the third in Split into panels by, with Shared y-axis on.
